class ip_ltx.generator_character_desc.CharacterFactory(s)¶

Базовые классы: object

Генератор характеристик(и) по заданной настройке.

Описывается конфигурационной секцией в ltx-файле. Генерирует список экземпляров класса Character.

Параметры:

s (Section) – Секция, на базе которой осуществляется инициализация.

Исключение:

IncompleteError – если настройка неполная (например, когда не указан обязательный параметр).

ip_ltx.generator_character_desc.form_characters(fp_in, fp_out, independent_input=False, tab='\t')¶

Сгенерировать XML-файл с характеристиками по заданной конфигурации.

Параметры:

  • fp_in (str) – Путь до файла с конфигурационными секциями.

  • fp_out (str) – Путь до файла, куда выписываются сформированные характеристики. Директория этого файла должна быть подготовлена заранее.

  • independent_input (bool) – Если True, то перед обработкой данного файла генератор забудет о всех ранее сгенерированных характеристиках в рамках текущей сессии.

  • tab (str) – Отступ, используемый при выводе в файл.

Исключение:

CharacterFactory.IncompleteError – при ошибке в конфигурации.

Тип результата:

None

ip_ltx.generator_character_desc.generate(fps, independent_input=False, output_dir=None, tab='\t')¶

Сгенерировать характеристики NPC по данным файлам.

  • Местный аналог функции-обёртки run().

  • Перехватывает любые исключения и выводит информацию о них.

  • Также предварительно валидирует все необходимые для работы синглтоны.

Параметры:

  • fps (list[str]) – Список файлов с настройками характеристик.

  • independent_input (bool) – Если True, то перед обработкой каждого нового файла генератор будет забывать о характеристиках, сгенерированных на основе предыдущего файла.

  • output_dir (str | None) – Существующая директория для выводимых файлов. Если None, то вывод осуществляется в текущую директорию.

  • tab (str) – Отступ, используемый при выводе в файлы.

Тип результата:

None
