ip_ltx.analyzer_general module¶

Базовый инструментарий для извлечения кастомной информации из конфигов

ip_ltx.analyzer_general.extract__addon_to_wpn(fn, dont_ignore_sections=False)¶

Для каждого аддона извлечь список стволов его использующих.

Параметры:

  • fn (str) – Путь/имя файла для вывода.

  • dont_ignore_sections (bool) – Не игнорировать секции, перечисленные в мета-файле в [ignore_sections].

Тип результата:

None

ip_ltx.analyzer_general.extract_fields(fn, precond, fields, fields_pp=None, sort=None, as_blocks=False, dont_ignore_sections=False)¶

Итерация по всем секциям system.ltx и извлечение полей.

Параметры:

  • fn (str) – Путь/имя файла для вывода.

  • precond (Callable[[Section], bool]) – Функция-фильтр секций.

  • fields (list[str]) – Список полей для извлечения.

  • fields_pp (list[Callable[[str | None], str | int | float]] | None) – Список функций для постобработки значений соответствующих полей. Должен совпадать по размеру с fields.

  • sort (int | None) – Режим сортировки выводимых секций. None - без сортировки. 0 - по имени секции. Больше 0 - по соответствующему полю.

  • as_blocks (bool) – Режим вывода. True - вывести каждую секцию отдельными блоками. False - вывести в формате таблицы (одна секция - одна строка).

  • dont_ignore_sections (bool) – Не игнорировать секции, перечисленные в мета-файле в [ignore_sections].

Тип результата:

None

ip_ltx.analyzer_general.extract_monsters_health(fn, hit_power_wound=2.5, hit_power_fire_wound=0.5, dont_ignore_sections=False)¶

Вывод информации о том, за сколько хитов/ударов/попаданий умирает мутант.

Вывод осуществляется по каждому мутанту, по каждой перечисленной в его конфиге кости, по двум типам урона (wound и fire_wound).

Параметры:

  • fn (str) – Путь/имя файла для вывода.

  • hit_power_wound (float) – Величина урона типа wound, используемая при расчётах фатального кол-ва ударов.

  • hit_power_fire_wound (float) – Величина урона типа fire_wound, используемая при расчётах фатального кол-ва попаданий.

  • dont_ignore_sections (bool) – Не игнорировать секции, перечисленные в мета-файле в [ignore_sections].

Тип результата:

None
