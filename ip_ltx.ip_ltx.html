ip_ltx.ip_ltx module¶

ip_ltx¶

Базовые классы для работы с ltx-файлами.

Отличия от CInifile (X-Ray Engine):¶

  • Сохранён порядок определения секций и их полей.

  • Поле без значения и поле с пустым значением различаются между собой.

  • Отличие местных методов получения значения get_* от движковых r_*:

    • Позволяют читать из секции с пустым ID.

    • Не переводят в нижний регистр данный ID секции.

    • Позволяют задать значение по умолчанию (defval).

    • Более придирчивы к формату при преобразовании к другому типу (float, s32, u32, bool).

  • …

class ip_ltx.ip_ltx.Ini(name='', ini_meta=None)¶

Базовые классы: object

Класс, считывающий ltx-файл(ы).

Аналог LUA-класса ini_file (CScriptIniFile) и движкового CInifile.

Параметры:

  • name (str) – Имя экземпляра класса. Используется при выводе ошибок.

  • ini_meta (Self | None) –

    Экземпляр этого же класса с настройками путей папок gamedata. Эти настройки полезны для последующего чтения файлов из gamedata. Пути указываются в секции [settings]:

    • gamedata_path_mod - путь до основной папки gamedata; как правило, это просто папка gamedata мода; указывается обязательно.

    • gamedata_path_alt - путь до альтернативной папки gamedata; как правило, это разархивированные gamedata.db*; указывать не обязательно, если в основной папке gamedata уже содержатся все ресурсы игры.

Исключение:

Ini.Error – при ошибке инициализации.

read_raw(raw, fp_src=None, preserve_value_whitespaces=False)¶

Считывание данных о секциях непосредственно со строки (str).

  • Поддерживает наследование (в т.ч. множественное).

  • Поддерживает include-директивы.

  • Для поля custom_data поддерживается формат многострочного значения. Синтаксис: custom_data = <<END (new lines) END (типа heredoc из Perl). Таким образом, поддерживается чтение ltx-файлов, полученных декомпиляцией all.spawn через ACDC.

Параметры:

  • raw (str) – Текст с данными.

  • fp_src (Path | None) – Путь к файлу, откуда взят текст. Необходимо для поддержки #include, а также Section._src.

  • preserve_value_whitespaces (bool) – При чтении значения поля сохранить все его пробельные символы (кроме тех, что с краю). По умолчанию они сохраняются только если находятся между парой кавычек.

Исключение:

Ini.Error – при ошибке считывания.

Тип результата:

None

get_items(k, mandatory=True, parsing_mode='comma')¶

Парсит строку вида <section>,<count>,<section>,<section>,... в список пар (<section>, <count>).

Аналог LUA-функции xr_box.r_items, но допускает только целые числа (в том числе отрицательные).

Параметры:

  • k (str) – Имя поля, значение которого нужно считать.

  • mandatory (bool) –

    Определяет поведение функции в случае, когда поля нет или оно без значения:

    • mandatory=True: выдаст исключение

    • mandatory=False: вернёт пустой список

  • parsing_mode (Literal['comma', 'vanilla', 'vanilla_ext']) –

    Как исходная строка будет преобразована в список:

    • comma - обычное разбиение по запятым.

    • vanilla - алгоритм, повторяющий LUA-функцию _g.parse_names. Не поддерживает точки и дефисы в элементах списка. Не поддерживает отрицательные числа.

    • vanilla_ext - алгоритм, повторяющий альтернативную LUA-функцию parse_names, использующуюся в скриптах se_respawn, task_manager, treasure_manager, xr_box. Поддерживает точки и дефисы внутри элементов списка. Не поддерживает отрицательные числа.

Исключение:

Section.Error – если поля нет или оно без значения, и при этом mandatory=True.

Результат:

Список пар (<section>, <count>).

get_pair(type_caster, type_label, k, sep)¶

Получить значение поля как пару элементов нужного типа.

Базовый метод для ряда других методов (get_pair_*).

Параметры:

  • type_caster (Callable[[str], R | None]) – Функция для конвертации элементов в нужный тип, возвращающая None в случае невозможности конвертации.

  • type_label (str) – Текстовое обозначения типа. Используется в сообщении исключения.

  • k (str) – Имя поля.

  • sep (str) – Разделитель, по которому из строкового значения поля получается список.

Исключение:

Section.Error –

в одном из трёх случаев:

  1. Указанного поля нет или оно без значения.

  2. Размер списка не равен двум.

  3. Конвертация значения хотя бы одного элемента невозможна.

Результат:

Построенная по строковому значению поля пара элементов нужного типа.

Тип результата:

tuple[R, R]

write(file, fields_mask=None, first=(), value_getter=None)¶

Запись секции в файл.

  • Поддерживает вывод многострочных значений для поля с именем custom_data. Таким образом, поддерживается совместимость с ltx-файлами, используемыми ACDC для компиляции all.spawn.

Параметры:

  • file (TextIO) – Открытый файл для записи.

  • fields_mask (str | None) – Маска-фильтр, определяющая, поля с каким именем выводить. Задаётся регулярным выражением. Проверяется полное совпадение. Если None, то выводит все существующие поля секции.

  • first (tuple[str, ...]) – Перечисление имён полей, которые нужно вывести в первую очередь. В остальном, поля выводятся в том порядке, в котором они изначально были записаны в секцию.

  • value_getter (Callable[[Self, str], str | None] | None) –

    Функция, определяющая то, как по данной секции и имени её поля будет получено значение.

    • По умолчанию (если указано None) используется непосредственное значение, получаемое методом field().

    • Переопределение этого параметра может быть использовано для предобработки значений перед их выводом.

    • При любом вызове этой функции гарантируется, что указанное поле в указанной секции существует.
