ip_ltx.utils.fill_environ(globalns)¶

Заполнить переменные среды из глобальных перменных.

  • META_FILEPATH: str

    • Путь до основного конфигурационного файла.

    • Значение по умолчанию: файл meta.ltx в текущей рабочей директории.

  • HIDE_LTX_WARNINGS: bool

    • Спрятать сообщения о некритических ошибках при чтении/парсинге ltx-файлов.

    • Значение по умолчанию: False

  • HIDE_XML_WARNINGS: bool

    • Спрятать сообщения о некритических ошибках при чтении/парсинге xml-файлов.

    • Значение по умолчанию: False

  • HIDE_EXTRA_WARNINGS: bool

    • Спрятать сообщения о других некритических ошибках (например, при инициализации SpawnEntry)

    • Значение по умолчанию: False

Параметры:

globalns (MutableMapping)

Тип результата:

None

ip_ltx.utils.is_gamedata_dir(path, gd_path_main, gd_path_alt)¶

Проверка, существует ли папка в ресурсах игры (gamedata).

Параметры:

  • path (str) – Путь до папки относительно папки gamedata.

  • gd_path_main (Path | None) – Путь до основной папки gamedata.

  • gd_path_alt (Path | None) – Путь до вспомогательной папки gamedata. Например, до ресурсов оригинальной игры или распакованных db-архивов.

Результат:

Была ли найдена указанная папка хотя бы в одной из папок gamedata.

Тип результата:

bool

ip_ltx.utils.run(f, tag, **kwargs)¶

Обёртка для безопасного запуска функции, генерирующей текстовый файл с данными.

  • Формирует имя выходного файла, беря в качестве префикса имя исходного скрипта.

  • Перехватывает любые исключения и выводит информацию о них.

Параметры:

  • f (Runnable) – Функция для запуска. Первым аргументом должна принимать имя выходного файла.

  • tag (str) – Суффикс выходного файла (без расширения).

  • **kwargs (Any) – Остальные аргументы функции после имени выходного файла.

Тип результата:

None
